# Crystallography from a lift condition

Supplementary material for the preprint of the same name
(*Geometry of the vacuum*, floor 0).

The paper is `preprint6_en.md` (source) and `preprint6_en.tex` / `preprint6_en.pdf` (typeset).
Everything else in this repository exists so that the paper's computational statements can be
**re-run rather than believed**.

## Which claim rests on which file

| statement in the paper | where it is checked | what the check reports |
|:--|:--|:--|
| §2 — the daughter metric is *forced*: `dim Hom_{so(η)}(Λ²V, Λ²A) = 1`, the bracket is `β = −η\|W` | `S1588_lift_inventory` | prints the dimension count and the residual (~10⁻¹⁶) |
| §4 — a lattice lifts to the Heisenberg group iff `MᵀBM` is integral up to one factor; the point group of a β-integral lattice is infinite, maximal modulus `(2+√3)² = 7+4√3 ≈ 13.93` | `S1588_lift_inventory`, `S1598_infinite_states` | `0 of 50` generic lattices lift; the hyperbolic isometry is exhibited by hand |
| §3 / §4 — no canonical lattice; finite states give a trivial point group | `S1598_infinite_states` | 3-dimensional orbits; effective point group `{±I}` on the winning class |
| §5 — positivity cuts the Levi to a compact `SO(3)×SO(2)`; the arithmetic side is thick | `S1602_compactifier` | Killing form `[−4..−4]` (compact) vs `[−4..+4]` (a boost); orbit density does not decay |
| §5 / §9 — the covolume of `O⁺(I_{3,1}) = [3,4,4]` is `V = 0.0763304662`; density `1/(48V) = 0.27294` vs count `0.2727` | `S1622_covolume` | computes `V` and the density, compares to the direct count |
| §6 — the type map of the standard lattice: strata with `\|K∩Γ\| = 192, 32, 4, 2`, identified by order-histogram | `S1604_state_type_map` | the four strata and their histograms; the composition is a type invariant |
| §6 / §9 (Theorem 1(7)) — the section law: a rank-`p` lattice is a section of `I_{p,1}` iff its discriminant form is cyclic `⟨1/n⟩`; the holohedry-image count is `[3,7,13]` at `p = 2,3,4` | `S1624_nikulin_image` | `13/13` sections reproduced from the discriminant form alone |
| §6 / §9 — the minimal section norm per holohedry is exact, `n_min = (1,2,6,7,11,13,43)`, over `det ≤ 43` | `S1629_nmin_exact`, `S1633_nmin_exact_ver2` | exhaustive enumeration; `S1633` re-runs it with an exact split-disc filter (no coordinate box) and finds `0` disagreements on 1150 lattices |
| §7 — the genus refines the SNF proxy: 11 buckets at `\|det\| ≤ 8` split into **at least 19** genera | `S1630_genus` | the split is exhibited; `det 1` stays a single class |

## Reproducing

```
cd src/symbolic
python S1588_lift_inventory.py
python S1598_infinite_states.py
python S1602_compactifier.py
python S1604_state_type_map.py
python S1622_covolume.py
python S1624_nikulin_image.py
python S1629_nmin_exact.py
python S1630_genus.py
python S1633_nmin_exact_ver2.py
```

Python 3, with `numpy` / `sympy` where a probe's imports call for them. Each probe prints the same
output recorded beside it in `*_run.log`; the four probes that use the shared harness read it from
`../../test/`, so run them from `src/symbolic`. Every log in this package was **regenerated by execution**
in this repository, not edited.

Several probes end with a score line — a set of detectors, each of which was required to **fail on a
named negative world** before it was allowed to pass. A check that cannot fail is not evidence; that is
what `test/_teeth.py` enforces.

## Two notes, so nothing looks like an oversight

**On the identifiers.** The probes are named by short labels such as `S1604`. These are not references to
a private system: each one is a file in this repository, listed in the tables above and bound to the
statement it supports. Every log was produced by running the file as it stands here.

**On one correction.** Two numbers in an earlier draft were wrong and were corrected before this release;
neither superseded value appears in the shipped code or logs. The correction is recorded in `history/ERRATA.md`.
